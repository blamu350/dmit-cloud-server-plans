## Pro、EB、T1 三档线路差在哪

**Premium（Pro）** 是旗舰线。洛杉矶走三网 CN2 GIA，电信联通去程 CN2 GIA、移动去程 CMI，三网回程都回 CN2 GIA；香港是电信双向 CN2 GIA，移动联通直连。晚高峰最稳，价格也最贵。

**Eyeball（EB）** 是中间档。洛杉矶 EB 走优化线路，资料里对具体走向有两种说法，一种写 CMIN2，一种写电信联通 AS9929 加移动 CMIN2，共同点是都在 Pro 的 CN2 GIA 之下；香港 EB 走三网 CMI。联通和移动用户在这条线上体验和 Pro 的差距比电信用户小。

**Tier 1（T1）** 是纯国际线路，不含大陆优化。适合面向海外用户的站点、API 节点、CDN 边缘节点。它的一个好处是流量超了只限速不停机，也不额外收费。

这是很多人看到价格表会愣一下的地方。AN4 平台上：

- LAX.AN4.Pro.MINI **$72.90/月**，4 核 4G / 80G SSD / 5000GB
- LAX.AN4.EB.MINI **$72.90/月**，4 核 4G / 80G SSD / 10000GB

入门档也是这个规律，量级小一些：同样 $9.99 的 TINY，Pro 给 1000GB，EB 给 1500GB。香港那边，HKG.AS3.EB.TINY 和 HKG.AS3.Pro.TINY 都是 **$39.90**，EB 流量 800GB，Pro 500GB。

所以这道选择题可以简化成一句话：你多花的钱买的是电信回程那一段 CN2 GIA。电信用户走 Pro 收益明显；联通、移动用户如果主要跑下载、备份、转发性流量，EB 多出来的那一倍流量更实在。

## 四个机房怎么选

延迟是决定性的指标，第三方测评给出的量级：

- **洛杉矶**：国内三网 **150–180ms**，晚高峰丢包率低。物理距离摆在那，再优化也压不到 100ms 以内。
- **香港**：**10–50ms**，有测评测到平均 39ms，基本不丢包。面向大陆用户的首选。
- **东京**：三网高速优化，但只有 T1 和 Pro 两条线，套餐选择比香港少。
- **圣何塞**：只有 T1，带 20Gbps DDoS 防御，做防护型站点可以看。

建站面向国内用户，香港的低延迟值那个溢价；预算有限又不想放弃优化线路，洛杉矶 Pro 是最常见的折中；纯海外业务，机房按用户地理位置挑就行，T1 就够。

## 六条会直接影响使用的限制

这几条在套餐页上不显眼，但会决定你能不能用：

1. **只有 Linux**。没有 Windows VPS，别指望装 Windows Server。
2. **强制 SSH 密钥登录**，不支持 root 密码。第一次买完要去后台下载密钥文件，再用 SSH 客户端连。对习惯密码登录的人是第一道坎。
3. **达量限速，不停机**。这个数值差别很大：LAX AS3 Pro 的 TINY/Pocket/STARTER 超量后限到 **4Mbps**，MINI/MICRO 限 **8Mbps**，MEDIUM 限 **10Mbps**；LAX T1 的 WEE 限 **100Mbps**，TINY 到 MINI 限 **200Mbps**，MICRO 限 **500Mbps**；香港和东京 T1 从 WEE 的 **50Mbps** 一路到 GIANT 的 **1Gbps**。拿 Pro 的入门档跑大流量下载，超量后会很难受。
4. **非 Pro 线路可能切路由**。因为攻击或成本原因，EB 和 T1 的路由有被调整的可能。对优化线路是硬需求的话，直接上 Pro。
5. **维护不一定提前通知**。硬件升级维护有用户反馈过没收到邮件，跑关键业务要自己有预案。
6. **热门套餐经常缺货**。控制单机用户数是不超售的代价，购物车里整排 Out of Stock 是常态，看到有货别拖。
